# Tutoring with Santi

Single-page site for private math, physics, and chemistry tutoring.
Static HTML + CSS, no build step, no dependencies.

- `index.html` — the page
- `styles.css` — all styles
- `assets/santi.png` — portrait

## Publishing (GitHub Pages)

1. Push these files to the repository root on the `main` branch.
2. Settings → Pages → Source: "Deploy from a branch" → `main` / `/ (root)`.
3. The site goes live at `https://<user>.github.io/<repo>/` within a minute or two.

For a custom domain, add it under Settings → Pages and create a `CNAME` file
containing the domain.
